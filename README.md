# Claude Agent Core

Агентное ядро на базе Claude с мультимодельным роутингом и горячей подгрузкой модулей. Изначально построено как личный Telegram-ассистент для соло-практики автоматизации (Automatiko) — сейчас выделено как отдельный showcase-репозиторий: только код ядра, без личных данных и без рабочих секретов оригинального деплоя.

## Что внутри

- **Мультимодельный роутинг** (`bot/bot.py`) — сложные задачи уходят к Claude, простые к DeepSeek (дешевле на порядок), голос — к Groq Whisper.
- **Модульная система с горячей подгрузкой** (`modules/`) — каждый модуль (`calendar`, `weather`, `search`, `bash`, `memory`, `scheduler`, `todos`, `corpus`, `kwork`, `self_modify`) описан `manifest.json` и подключается без перезапуска ядра.
- **Модуль памяти** (`modules/memory/`) — интеграция с внешним сервером долгосрочной памяти (см. [memory-api](https://github.com/MangasarovDR/memory-api)).
- **Self-modify** (`modules/self_modify/`) — агент может предлагать и применять правки собственного кода под контролем подтверждения.

## Стек

Python, python-telegram-bot, Docker.

## Статус

Код показан как есть, без адаптации под чужое окружение: настройка ключей, деплой и специфика конкретного использования (Kwork-мониторинг, календарь) оставлены как пример реальной интеграции, а не как готовый к копированию сервис.
